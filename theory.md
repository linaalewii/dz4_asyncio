# Теоретическая часть

1. **Парсер, считающий хеши 10 000 файлов — процессы.**
   Это CPU-bound задача, а из-за GIL потоки не дадут параллельных вычислений, тогда как процессы работают на разных ядрах.

2. **Бот, который на каждый запрос обращается к 5 внешним API — async.**
   Это I/O-bound задача: пять запросов можно запустить через `asyncio.gather` и ждать их одновременно в одном потоке, без накладных расходов на потоки.

3. **Скрипт, выгружающий 100 000 строк из БД пачками — async.**
   Это I/O-bound задача: пока БД готовит очередную пачку, программа может заниматься другой работой (нужен асинхронный драйвер, например `asyncpg`; если драйвер только синхронный, его вызовы выносят в поток через `asyncio.to_thread`).
